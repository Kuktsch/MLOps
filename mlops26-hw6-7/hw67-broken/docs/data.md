# Данные и контроль утечки

Train/val скопированы побайтно из HW4, продолжая HW3 v2 и HW5.
`metrics/data-provenance.json` содержит SHA256 исходных JSONL и тензоров,
хеш params HW4 и DVC lock HW3. `scripts/verify_hw4.py` повторно применяет
оригинальную `encode_example` HW4 ко всем 3345 train и 418 val записям:
совпадают id, input_ids, attention_mask и labels каждого примера.
Результат — `metrics/tokenization-proof.json`. Упакованные тензоры не используются.
Индекс содержит все 3345 исходных train-вопросов, а не только пул из 32.

Golden v1 составлен отдельно до генерации: 54 вопроса, три среза по 18.
Эталонные позиции A/B/C сбалансированы: по 18 каждого типа. Варианты
содержат один правильный ответ, не допускают множественного выбора.
Источники указаны в каждой строке:

- География: поле Capital city в профилях [UNData](https://data.un.org/legacy/en/iso/fi.html).
- Химия: символы элементов [IUPAC](https://iupac.org/what-we-do/periodic-table-of-elements/).
- Астрономия: [размеры и порядок планет](https://science.nasa.gov/solar-system/planet-sizes-and-locations-in-our-solar-system/)
  и [описание Солнечной системы NASA](https://science.nasa.gov/solar-system/solar-system-facts/).

Для вопросов заданы источники, допустимые метки и однозначные эталоны.
Проверены эталоны, все варианты ответа и однозначность формулировок 54 golden-вопросов
и трёх behavioral-кейсов. Ошибок меток и вопросов с несколькими правильными вариантами
не обнаружено. Проверка источников не является независимым аудитом качества.
Примеры преподавателя в набор не включены. География и химия имеют
повторяющиеся шаблоны, но каждый вопрос проверяет отдельный факт о другом объекте.
В астрономии есть вопросы о классификации, числе объектов, размерах и отношениях.

Группировка выполняется по предмету вопроса: страна/элемент/астрономический
объект. Повторные вопросы о Меркурии, Юпитере и Сатурне остаются в одной
golden-группе. Format и paraphrase связаны с geography-01 через capital-fi;
во втором случае Хельсинки перенесён из позиции A в C и эталон обновлён.
Refusal проверяет запрос кода вне заранее определённой энциклопедической темы.
Behavioral не прибавляются к n=54.

Нормализованные точные совпадения и group_id проверяет штатный
`validate_golden`. Дополнительно просмотрены ближайшие вопросы полного
train (`metrics/leakage-review.json`) и совпадения по предметным словам.
Обнаружены вопрос об Оттаве (ru-3339822-146441025), вопрос о горах Максвелла
на Венере (ru-806-149812417) и об аппарате «Венера-15» (ru-355418-148894217).
В golden исключены вопросы о столице Канады и фактах о самой Венере.
Совпадения «серебро» с чеканкой монет, «медь» со спектаклем, «железо» с
железными дорогами не являются вопросами о химическом символе.
Упоминания стран в исторических/биографических вопросах не используют
статью-источник UNData и не повторяют вопрос о столице.

Идентификаторы исходных групп HW3 сохранены в индексе без переименования;
новые авторские группы имеют собственные смысловые имена. Нулевое
пересечение этих пространств имён само по себе не доказывает независимость:
поэтому приведён дополнительный предметный разбор. Поиск по словам не
гарантирует отсутствия всех перефразов. Пересечения с корпусом
предобучения Qwen в рамках работы не проверялись. Это регрессионный набор, не аудит
неизвестных модели знаний и не репрезентативная оценка длинных ответов HW3.

## Проверка разметки

| Группа | Число вопросов | Результат |
|---|---:|---|
| География | 18 | Столицы сверены с UNData; в каждом вопросе один правильный город |
| Химия | 18 | Символы сверены с таблицей IUPAC; названия и регистр символов корректны |
| Астрономия | 18 | Порядок, размеры и классификации сверены с NASA; правильные варианты однозначны |
| Behavioral | 3 | Для format сохранён A; для переставленного paraphrase верен C; запрос программы требует REFUSE |

В astronomy-17 положение главного пояса астероидов дополнительно подтверждено
[страницей NASA об астероидах](https://science.nasa.gov/solar-system/asteroids/).
Вопросы о размерах относятся к восьми планетам, Плутон отдельно обозначен карликовой
планетой. Уран и Нептун относятся к ледяным гигантам, Юпитер и Сатурн — к газовым.
В chemistry-03 несуществующий символ L является неверным вариантом, а не ошибкой
эталона Li. Behavioral-перефраз сохраняет смысл вопроса и обновляет метку после
перестановки вариантов; отказ соответствует заранее заданной границе темы.

Метки A/B/C распределены поровну, но идут циклически; порядок вариантов не
рандомизирован. Шаблонность и связанные вопросы ограничивают независимость набора.

## DVC и доступ преподавателю

Версии данных описаны в `data/eval.dvc`, `data/source.dvc`,
`data/tokenized.dvc` и `.dvc/config`. Локальный remote `.dvc-storage/`
отделён от HW3. Веса и тензоры в Git и комплект сдачи не входят.
`submission/evaluation-data.zip` содержит три JSONL и только DVC-объекты
набора оценки. Восстановление DVC-данных после распаковки архива
в корне `hw67-broken`:

```bash
uvx --from dvc==3.67.1 dvc pull data/eval.dvc
uvx --from dvc==3.67.1 dvc status --json data/eval.dvc
```

Пустой JSON-объект `{}` в выводе `dvc status --json` означает отсутствие
расхождений. Восстановление из DVC-объектов архива проверено в отдельном
проекте без исходных JSONL; все файлы совпали. Изменение временной копии
golden-файла выявлено DVC (`metrics/dvc-restore-check.json`).

Вход обучения — выход стадии tokenize HW4. Команда `make prepare`
импортирует тензоры и исходные JSONL из соседнего каталога HW4. Проверка
соответствия тензоров исходным записям выполняется командой:

```bash
uv run --no-project --python ../../hw4-broken/.venv/bin/python python scripts/verify_hw4.py
```

Цепочка восстановления исходных данных: закреплённый источник HW3 v2 →
групповое разделение → токенизация HW4 с сохранённой конфигурацией.
