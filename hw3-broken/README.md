# MLOps HW3 — Russian Encyclopedia QA + DVC

**Состояние архива:** исходный код и конфигурация исправлены; сам внешний parquet
и результаты v1/v2 в архив **не включены**: среда создания архива не могла
скачать Hugging Face, поэтому реальный `make check` и `dvc repro` ещё не выполнялись.
Здесь нет фиктивных JSONL, метрик или утверждения «8/8 passed».

## Задача и источник

Собственный русскоязычный chat-SFT датасет энциклопедических пар вопрос/ответ;
основан на [levos06/ru_wiki_qa](https://huggingface.co/datasets/levos06/ru_wiki_qa).
Согласуйте эту **тему** с преподавателем, уникальность темы не проверяется кодом.
**Важно:** скачиваемый `final_qa_dataset.parquet` содержит только `question`,
`answer`, `original_id`. Полей `text` и `quality_prob` в компактном файле **нет**.
Поэтому этот проект не утверждает, что ответ основан на приложенном контексте;
сообщение пользователя содержит вопрос, и фильтр quality_prob пропускается.
Это исправление ошибки предыдущей версии проекта: она неверно требовала `text`.
`data/source/ru_wiki_qa.parquet` скачивается из pinned revision `23b9d3a`;
SHA256 проверяется **перед** его использованием. Для скачивания нужен интернет.
Доступ к GPU, OpenAI API или другим платным API не требуется.

## Самый короткий путь (из WSL с интернетом)

```bash
cd hw3-broken
bash scripts/finish.sh
```

Эта команда установит зависимости, скачает и проверит исходник, построит обе
версии, создаст **два Git-коммита**, запишет реальные метрики и запустит восемь
проверок. Предварительно должен быть установлен `uv` и настроен Git author.
Если какая-либо проверка упадёт, скрипт остановится с ошибкой — не будет
создавать видимость зачёта.

## Установка в WSL / Ubuntu

```bash
cd hw3-broken
uv sync --python 3.12
make repro
make check
make contamination
```

`make repro` автоматически скачает файл (~37.3 MB), выполнит
source → collect → clean → diversity → split и заполнит `docs/datasheet.md`
**реальными**, а не демонстрационными числами. Выходы DVC сохраняются в
`data/`; локальный remote `.dvc-storage/` намеренно исключён из Git.
Если скачивание Hugging Face недоступно, можно вручную положить оригинальный
`final_qa_dataset.parquet` в `data/source/ru_wiki_qa.parquet` и повторить
`make repro`; неверный SHA256 остановит выполнение.

Вариант с ручной загрузкой через браузер:
https://huggingface.co/datasets/levos06/ru_wiki_qa/blob/main/final_qa_dataset.parquet

Если источник изменится/файл пропадёт, его **нельзя** молча заменять
произвольной выборкой: нужно обновить `source.revision`, `source.sha256`
и отразить изменение происхождения в datasheet.

## Версии

```bash
make v1     # collect.rows.v1: 2600 до очистки
make v2     # collect.rows.v2: 4200 до очистки
make diff   # dvc metrics diff HEAD~1 HEAD, требует двух Git-коммитов
```

`make versions` делает оба прогона, `dvc push` в настроенный local remote,
создаёт **два реальных коммита** (`v1`, `v2`) и сравнивает метрики.
**Внимание:** `make versions` автоматически создаёт Git-коммиты; запускайте
его в отдельной HW3-папке/ветке, когда настроены `git user.name/email`.
Если HW3 вложен в большой общий Git репозиторий с HW1/HW2, используйте
отдельную ветку и проверяйте `git status` перед запуском.

```bash
git init                 # только если репозитория ещё нет
git config user.name "Your Name"     # если не настроено
 git config user.email "you@example.com"  # если не настроено
make versions
make check
```

В Git добавляют `uv.lock`, `dvc.lock`, скрипты, docs и метрики; **никогда**
не `data/`, `.dvc-storage/`, `.venv/`. У преподавателя без DVC-кэша,
исходного файла или сетевого доступа одних ссылок на local remote недостаточно
для `dvc pull`: поделитесь данными отдельно или перенесите DVC remote на
доступное хранилище по указанию преподавателя.

## Обработка

- По `original_id` группируем статьи Википедии (а не тематические semantic clusters).
- Детерминированное вложенное семплирование по SHA256, максимум 3 вопроса/статью.
- Отбор quality_prob ≥ 0.85 **только если колонка присутствует**;
  в компактном исходнике её нет, это отмечается в collect metrics/datasheet.
- 5 системных промптов, JSONL `id/topic/messages[system,user,assistant]`.
  В `user` включается исходный вопрос без вымышленного «Контекст: ...».
- Схема → длина → ПДн → exact duplicate → MinHash near duplicate.
- Гейт diversity обязателен и возвращает код ошибки при нарушении.
- Group-disjoint train/val/test по статье; встроенная и внешняя проверка утечек.

Два локальных «побочных» теста, не требующих скачивания датасета, можно
проверить через `uv run python -m unittest discover -s tests -v`.

## Ограничения

Автоматические ответы источника не являются вручную подтверждёнными фактами;
компактный исходник не включает исходных абзацев, поэтому факты нельзя
автоматически сверить с фрагментами Википедии. MinHash по словам
не находит все семантические парафразы. См. `docs/datasheet.md` после прогона
и `docs/defects.md`.
