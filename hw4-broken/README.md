# HW4 — подготовка собственного Russian Encyclopedia QA для Qwen3-0.6B

Стадия **tokenize** продолжает HW3 v2: JSONL → `input_ids`, `attention_mask`,
`labels` (только ответ ассистента под лоссом), метрики и отчёты. Весов модели не
нужно, только токенизатор.

## Запуск в WSL (Python 3.12 через uv)

Разместите `hw4-broken` рядом с `hw3-broken` в общем репозитории MLOps. В HW3
должна быть активна **v2**. Если там сейчас v1, из `hw3-broken` запустите:

```bash
uv run python scripts/set_version.py v2
make repro
```

Из `hw4-broken`:

```bash
uv sync --python 3.12
make import-hw3        # копирует существующие train/val из HW3 (не генерирует примеры)
make calibrate         # измеряет p50/p90/p99/max и выбирает max_seq_len по реальным токенам
make check             # tokenize + все 9 исходных проверок, без изменения tests/check.sh
```

Или `make prepare` вместо двух команд импорта и калибровки. Если JSONL уже лежат
в `data/`, импорт ничего не перезаписывает. Для явного повторного импорта:

```bash
uv run python -m scripts.import_hw3 --force
```

`make tokenize` выполняет стадию напрямую. Если нужен `make repro` через DVC,
один раз инициализируйте DVC в `hw4-broken` (внутри общего Git-репозитория):

```bash
uv run dvc init --subdir
make repro
```

При первом
запуске `uv sync` загрузит зависимости, а `make calibrate` — токенизатор
`Qwen/Qwen3-0.6B` из Hugging Face. Используется `uv.lock`, создаваемый командой
`uv sync` на вашей машине.

## Файлы результата

- `data/tokenized/train.pt`, `val.pt`: подготовленные последовательности.
- Packing отключён: в проекте нет блочно-диагональной attention mask, поэтому
  объединять независимые примеры в одну последовательность было бы некорректно.
- `metrics/tokenize.json`: реальные длины, маска, обрезка и прогноз времени.
- `docs/tokenize_report.md`: автоматически создаваемый отчёт.
- `docs/defects.md`: автоматически создаваемый разбор четырёх дефектов с
  реальными числами текущего запуска.

В Git коммитятся код, `uv.lock`, `params.yaml`, `dvc.yaml`, отчёты и метрики.
`data/` и `.venv/` в Git не попадают. Перед сдачей обязательно запишите видео
`make check` с финальной строкой и отпечатком **f2002c8c9519**.

## Важные границы воспроизводимости

Архив содержит код из исходного задания, но **не содержит ваши JSONL HW3**:
они остались на вашем компьютере, DVC/Git их не поставляют вместе с исходниками.
Прогноз использует медианную скорость генерации **26.6 ток/с** из ДЗ 1 на
RTX 3060 Ti. По условию ДЗ 4 обучение ожидается медленнее генерации в 2–3 раза,
поэтому отчёт показывает диапазон, а не выдаёт скорость генерации за скорость обучения.
Точный throughput будет измерен в ДЗ 5.
